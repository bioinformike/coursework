# stat-learning — Statistical Learning Exercises

Notes, exercises, and R code based on **An Introduction to Statistical Learning**.

Original repository: https://github.com/bioinformike/stat-learning

## Overview

This repository is a chapter-by-chapter collection of statistical-learning exercises and worked examples written in R. Unlike the other repositories in this coursework collection, no University of Cincinnati course number is attached to this repository, so this README is based only on the repository contents and its original README.

The repository explicitly identifies *An Introduction to Statistical Learning* as its source and contains work for Chapters 2 through 10.

## What this repository covers

The chapter organization follows the first-edition structure of *An Introduction to Statistical Learning*:

- **Chapter 2 — Statistical Learning**
  - Core supervised-learning concepts
  - Prediction versus inference
  - Model flexibility and the bias-variance tradeoff
- **Chapter 3 — Linear Regression**
  - Simple and multiple linear regression
  - Model interpretation and diagnostics
- **Chapter 4 — Classification**
  - Logistic regression
  - Linear and quadratic discriminant analysis
  - Classification concepts and evaluation
- **Chapter 5 — Resampling Methods**
  - Cross-validation
  - Bootstrap methods
- **Chapter 6 — Linear Model Selection and Regularization**
  - Subset selection
  - Shrinkage/regularization
  - Dimension-reduction approaches
- **Chapter 7 — Moving Beyond Linearity**
  - Polynomial regression
  - Splines and other nonlinear modeling approaches
- **Chapter 8 — Tree-Based Methods**
  - Decision trees
  - Bagging and random forests
  - Boosting
- **Chapter 9 — Support Vector Machines**
  - Maximal-margin classifiers
  - Support vector classifiers and kernels
- **Chapter 10 — Unsupervised Learning**
  - Principal components analysis
  - Clustering
